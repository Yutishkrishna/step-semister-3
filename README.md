# Week 3 – OOP Practice Problems (Category B)

Java solutions for the Week 3 OOP practice set, covering classes, objects, constructors, encapsulation, and static vs instance members.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| M1 | Placement Records | Replacing parallel arrays with a class, constructors, arrays of objects |
| M2 | Encapsulated Mess-Card Wallet | Private fields, validation inside methods, read-only access |
| M3 | Overloaded Constructors for Course | Constructor overloading, `this()` chaining |
| M4 | Reference Copies — ID Card | Reference vs value copying, `==` identity |
| M5 | Instance vs Static — Student | Static fields/methods vs instance members |

## Files

- `Practice Problems/M1_PlacementRecord.java`
- `Practice Problems/M2_MessWallet.java`
- `Practice Problems/M3_Course.java`
- `Practice Problems/M4_IdCard.java`
- `Practice Problems/M5_Student.java`

Each file is self-contained and runnable — compile and run directly with `javac` and `java`.
