# Week 4 – OOP Practice Problems (Category B/C)

Java solutions for the Week 4 practice set, reinforcing constructor chaining, `this` keyword usage, `final` methods, static initializer blocks, and `instanceof`-based polymorphism.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| M1 | Library Book Cataloguing | Constructor chaining via `this()`, default field values |
| M2 | Payroll Batch Bonus Round | Resolving field/parameter naming clashes with `this` |
| M3 | Late Fees — Skip On-Time Accounts | `final` methods, conditional batch processing |
| M4 | One-Time College Setup | Static initializer blocks, batch object creation |
| M5 | Account Batch Payments | `instanceof`, polymorphic dispatch, counters |
