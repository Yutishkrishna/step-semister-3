# STEP Semester 3 — Week 10 Coding Assignment

Linked-list Category B solutions from the five uploaded problem PDFs.

| Problem | Java file | Main technique | Complexity |
|---|---|---|---|
| 1. Priority Token Insertion | A1_PriorityTokenInsertion.java | Singly linked list insertion | addFirst O(1); addLast O(n); insertAt O(n) |
| 2. Cancelled Orders Cleanup | A2_CancelledOrdersCleanup.java | Remove all matching nodes | O(n) time, O(1) extra space |
| 3. Reverse the Queue | A3_ReverseTheQueue.java | Three-pointer in-place reversal | O(n) time, O(1) extra space |
| 4. Train Coaches Both Ways | A4_TrainCoachesBothWays.java | Doubly linked list with head and tail | Find O(n); unlink O(1) |
| 5. Round-Robin Game Turns | A5_RoundRobinGameTurns.java | Circular singly linked list | addLast O(1); printTurns O(turns) |

Each program defines its own node class and does not use java.util.LinkedList.
