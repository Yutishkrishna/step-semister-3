# Week 1 – Assignment (5 Problems)

Java solutions for the Week 1 assignment, covering arrays, string traversal, and basic conditional logic.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| A1 | Exam Hall Seat Duplication Checker | Arrays, nested loops, conditional logic |
| A2 | Typing Speed Test Accuracy Checker | String traversal, `charAt()`, percentage calculation |
| A3 | Traffic Signal Streak Analyzer | String traversal, character comparison, tracking a running maximum |
| A4 | Warehouse Inventory Balancer | Arrays, sum accumulation, tracking maximum with its index |
| A5 | Movie Review Word Length Profiler | `split()`, loops, counting/categorization |
