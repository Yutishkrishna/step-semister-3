# Week 5 – Assignment (Category B, 5 Problems)

Java solutions for the Week 5 take-home assignment, reinforcing Java access levels (private, default, protected, public), cross-package subclass access, encapsulation guards, JavaBean conventions with write-once and write-only properties, and immutable receipts with defensive copying, static initialization blocks, and polymorphic batch dispatch.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| A1 | Membership Field Reach Checker | Java access levels, access classifier, per-modifier grouped summary |
| A2 | Reference Desk Subclass Reach | Protected cross-package access, early-exit scanning for first denied attempt |
| A3 | Book Copy Circulation Guard | Private state, constructor validation, boundary-safe state transitions |
| A4 | LibraryMember JavaBean & Security Answer Property | JavaBean conventions, write-once property, write-only property with one-way hashing |
| A5 | Immutable Loan Receipt & Nightly Circulation Ledger | True immutability, defensive copying in/out, wither pattern, static block, `instanceof` dispatch |
