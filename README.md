# Week 2 – Practice Problems (Day 2 Live-Coding, 5 Problems)

Java solutions for the Week 2 live-coding practice set, reinforcing core `String` methods with different real-world scenarios.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| P1 | Vowel & Consonant Counter | `charAt()`, loops, case-insensitive comparison |
| P2 | CSV Student Record Parser | `split()`, array length validation, formatted output |
| P3 | File Extension Validator | `lastIndexOf()`, `substring()`, `equalsIgnoreCase()` |
| P4 | Masked Phone Number Formatter | Digit validation, `substring()`, `StringBuilder` |
| P5 | Bank Transaction Reference Generator & Validator | `trim()`, `substring()`, `Character.isLetter()/isDigit()`, multi-stage validation |

## Files

- `Practice Problems/P1_VowelConsonantCounter.java`
- `Practice Problems/P2_CsvStudentRecordParser.java`
- `Practice Problems/P3_FileExtensionValidator.java`
- `Practice Problems/P4_MaskedPhoneNumberFormatter.java`
- `Practice Problems/P5_BankTransactionReferenceValidator.java`

Each file is self-contained and runnable — compile and run directly with `javac` and `java`.
