# Week 2 – Assignment (5 Problems)

Java solutions for the Week 2 assignment, covering core `String` methods: `length()`, `split()`, `substring()`, `trim()`, and `StringBuilder`.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| A1 | ATM PIN Length Validator | `length()`, if/else |
| A2 | Word Reversal Encoder | `split()`, `StringBuilder.reverse()`, string joining |
| A3 | Product Inventory CSV Parser | `split()`, array length validation, formatted output |
| A4 | Library ISBN Normalizer & Validator | `trim()`, `substring()`, `Character.isLetter()/isDigit()`, multi-stage validation |
| A5 | Stop-Word-Filtered Word Frequency Report | `replace()`, `split()` with regex, `HashMap`, sorting by count |

## Files

- `Assignments/A1_AtmPinLengthValidator.java`
- `Assignments/A2_WordReversalEncoder.java`
- `Assignments/A3_ProductInventoryCsvParser.java`
- `Assignments/A4_LibraryIsbnNormalizer.java`
- `Assignments/A5_StopWordFilteredWordFrequency.java`

Each file is self-contained and runnable — compile and run directly with `javac` and `java`.
