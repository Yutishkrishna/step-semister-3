# Week 5 – OOP Practice Problems (Category B)

Java solutions for the Week 5 practice set, reinforcing Java access levels (private, default, protected, public), subclass access across packages, encapsulation and invariant preservation, JavaBean conventions with write-only properties, and immutable classes with defensive copying and wither methods.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| M1 | Movie Ticket Field Visibility Checker | Java 4 access levels, access classifier, batch summary |
| M2 | Subclass Ticket Access | Protected cross-package access, own-type vs parent-type references |
| M3 | Seat Booking Encapsulation Guard | Private state, constructor validation, boundary-safe state transitions |
| M4 | MovieBookingProfile JavaBean & OTP Property | JavaBean specification, constructor chaining `this()`, write-only property |
| M5 | Immutable Booking Receipt & Nightly Settlement | Immutability, defensive copying in/out, wither pattern, `instanceof` polymorphic dispatch |
