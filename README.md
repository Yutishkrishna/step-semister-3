# Week 3 – OOP Homework Assignment (Category B)

Java solutions for the Week 3 OOP homework assignment, covering classes, objects, constructors, encapsulation, and static vs instance members.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| M1 | Library Inventory | Replacing parallel arrays with a class, constructors, arrays of objects |
| M2 | Encapsulated Payroll Account | Private fields, validation inside methods, read-only access |
| M3 | Overloaded Constructors for Employee | Constructor overloading, `this()` chaining |
| M4 | Reference Copies — Exam Hall Ticket | Reference vs value copying, `==` identity |
| M5 | Instance vs Static — Employee | Static fields/methods vs instance members |
