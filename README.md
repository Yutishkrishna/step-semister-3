# Week 1 – Practice Problems (Day 1 Live-Coding, 5 Problems)

Java solutions for the Week 1 live-coding practice set, covering randomization, recursion, arrays, and character-frequency logic.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| P1 | Rock-Paper-Scissors Game | Random generation, conditional logic, loops, basic statistics |
| P2 | Palindrome Checker (3 Approaches) | Loops, recursion, array manipulation, string comparison |
| P3 | BMI Calculator for a Team | Parallel arrays, arithmetic, conditional logic, formatted output |
| P4 | First Non-Repeating Character | Character frequency counting, early-exit scanning |
| P5 | Reverse Customer Name | String traversal, `StringBuilder` |

## Files

- `Practice Problems/P1_RockPaperScissors.java`
- `Practice Problems/P2_PalindromeChecker.java`
- `Practice Problems/P3_BmiCalculator.java`
- `Practice Problems/P4_FirstNonRepeatingChar.java`
- `Practice Problems/P5_ReverseCustomerName.java`

Each file is self-contained and runnable — compile and run directly with `javac` and `java`.
