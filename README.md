# Week 4 – Assignment (Category B, 5 Problems)

Java solutions for the Week 4 take-home assignment, reinforcing constructor chaining, the `this` keyword, `final` methods, static initializer blocks, and `instanceof`-based polymorphism — the same five concepts as the in-class set, with different scenarios.

## Problems

| # | Title | Concepts |
|---|-------|----------|
| A1 | Overloaded Constructors for Hackathon Registration | Constructor overloading, `this()` chaining, for-loop batch processing |
| A2 | `this` Keyword for Canteen Inventory | Resolving field/parameter naming clashes with `this` |
| A3 | Parking Overstay Fine Calculator | `final` methods, conditional batch processing |
| A4 | Library Membership Card Setup | Static initializer blocks, batch object creation |
| A5 | Canteen Closing-Time Payment Dispatch | `instanceof`, safe casting, inheritance, running totals |

## Files

- `Assignments/A1_HackathonRegistration.java`
- `Assignments/A2_CanteenInventory.java`
- `Assignments/A3_ParkingOverstayFine.java`
